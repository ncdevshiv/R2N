Definition of done — v1.0

  • Vertical slice: counter source → compiler → artifact → Rust runtime → memory renderer, with no dependency on JavaScript or Node.js anywhere in the runtime.
  • Real reactive loop: click → handler → state write → schedule → render → diff → minimal patch (SetText("1"), never recreate the parent).
  • Instance semantics: two Counter instances hold independent state; state identity = component identity + hook position.
  • Behavioral conformance: compatibility percentages published (React / JS / Web API / Ecosystem) instead of "the Counter works".
  • Language-independent ABI: the same artifact executes on Rust, Go, and Elixir runtimes passing identical conformance suites.
  • 1.0 exit test: a large existing React repository compiles and runs unchanged — zero JavaScript at runtime.
